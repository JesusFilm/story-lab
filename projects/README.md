# Projects

Tools and utilities. Each project has its own code, dependencies and setup instructions.

- [Story Diorama](story-diorama/README.md): reusable illustrated storytelling with timed text, scene transitions and soundtracks; Noah example and a standalone options playground.
- [Maze Foundry](maze-foundry/README.md): generate seeded mazes, inspect them and export PNG/JSON.
- [Pixal3D assets](pixal3d-assets/README.md): generate textured models from style references over SSH, then prepare and render static props with Blender.
- [Kokoro Voice Lab](kokoro-voice-lab/README.md): generate local 24 kHz WAV voice assets from reviewed text on an Apple Silicon Mac.

Playable experiments live under [Prototypes](../prototypes/README.md).
