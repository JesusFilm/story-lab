# Little Light Library original painted sources

These 21 PNG files are the unchanged ImageGen source outputs for the Little Light Library prototype: 16 story spreads, two transparent scene cutouts and three character cutouts. The exact prompts are preserved in [visual production notes](../../../prototypes/little-light-library/docs/visual.md). The current [visual style guide](../../../styles/little-light-library/README.md) governs them. The prototype owns optimized WebP copies in its own `public/assets/art/` folder; it does not load source art from the library.

Original artwork was generated with OpenAI ImageGen for this project in September 2026. No outside imagery or text is embedded. The images are creative visual staging of Genesis narratives, not source evidence for biblical or historical details. Verify all visual details before external publication.
