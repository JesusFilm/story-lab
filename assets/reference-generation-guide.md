# Reference images

Use the [shared style guide](../styles/README.md), the specific asset description,
and a few relevant grounding images. Keep the resulting image and a useful prompt
beside the asset, with descriptive filenames and relative links.

For humanoid reconstruction, show one full body, front-facing neutral T-pose with
empty hands and visible extremities. Use even lighting and a plain background.
For props and animals, use an informative three-quarter view. Keep separate views
consistent in identity, wardrobe, scale and lighting. Avoid text, collages, clipped
geometry and baked scene lighting. Preserve an alternative only if it is useful.

Inspect the resulting model for scale, geometry, materials and usable animation.
Keep technical caveats in a short README. Do not store approval conversations,
provider job histories or credit balances in the shared library.
