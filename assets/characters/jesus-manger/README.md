# Baby Jesus in the manger

[Follow the Light style](../../../styles/follow-the-light/README.md).

An isolated swaddled infant in a timber feeding trough with straw and linen, based on the ending artwork.

- `jesus-reference.png` and `jesus-reference.prompt.txt`: native ImageGen reference.
- `jesus-manger-tripo-detailed-source.glb`: current Tripo v3.1 source with detailed textures.
- `jesus-manger-tripo-detailed-provenance.json`: generation settings and source/reference hashes.
- `tripo-prepared/jesus-manger-tripo-detailed-runtime.glb`: current static runtime, 0.72 metres high before scene scaling.
- `tripo-renders/`: complete views of the current model.
- `jesus-manger-tripo-source.glb`: earlier Tripo model, retained for comparison.
- `jesus-manger-tripo-runtime.glb`: earlier prepared static runtime, 0.72 metres high with its base at zero.
- `renders/`: complete model views; `prepared/mesh-review.json` records geometry and textures.

The baby is intentionally static. Luke 2:16 places the baby in a feeding trough; the particular timber construction, bedding and facial appearance are artistic choices. This is an illustrative asset, not a historical reconstruction.
