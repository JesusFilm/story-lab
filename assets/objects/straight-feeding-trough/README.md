# Straight wall feeding trough

Separate rectangular hay-filled timber feeding trough, aligned to its principal axes and fitted to 1.8 × 0.45 × 0.65 m. Four independent prototype placements follow the four wall directions; the front copy is shorter to keep the main entrance clear.

Style: [Follow the Light](../../../styles/follow-the-light/README.md).

Generated from native ImageGen artwork with TencentARC/Pixal3D. Atlas-preserving preparation uses 2048px matte textures. Sources and earlier preparation variants are preserved. These are illustrative Judean-inspired props, not archaeological reconstructions.

The 30k-triangle derivative damaged plank edges and is not used. The detailed derivative retains about 150k triangles before alignment. Preparation: `projects/pixal3d-assets/align-feeding-trough.py`.
