# Editable scene sources

Blender files preserve the editable prototype scenes. Available textures are packed except for the teacher, whose full-resolution textures
live in `textures/` and use relative links. The teacher source already lacked
`teacher-cloth.png` and `T_Hair_1_Normal_png.png`; these references remain unresolved.
The exported runtime models are separate and remain unchanged.

Teacher source textures retain the [model source credits and licenses](../public/models-v2/CREDITS.md).
