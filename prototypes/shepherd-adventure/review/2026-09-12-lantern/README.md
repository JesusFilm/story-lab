# One-stall lamp study

Source: clean main b54fdd5d19ef0018a55edea1d2b0a10f23c970d9. Direction: the user's
12 September request for deliberate assembly, clear components and retryable failure.
Visual reference: Follow the Light AA and the existing carried bronze lantern.

Baseline evidence is the earlier [first interaction capture](../2026-09-11-light-and-camera/first-interaction.jpg)
and the three-stop model on main. It is historical, not a matched new camera capture.
The previous system had no first-person screen or failure state to compare directly.
New ready/failure/lit and 390×844 mobile captures use Chrome, reduced motion.

Acceptance: assemble in one place; visible oil and wick marks; discrete inputs;
incorrect setup has a concrete explanation; retry resets; only success awards a
lantern. All pass model and browser checks. The original preparation detours are
removed from route choices and their separate tables replaced with one covered stall.
A native ImageGen backdrop supplies the atmosphere; the simplified SVG lamp cutaway
supplies readable, editable parts. This is a 2D first-person minigame, not a newly
modeled 3D assembly. No paid Tripo generation was necessary.

All 50 component combinations checked. Browser: premature spark, retry, successful
assembly, keyboard Enter/Space, Escape, mobile fit, actual-game inventory award.
Journey checks cover both full routes, pause, recovery and 82-state reachability.
No browser page errors observed. Physical-device feel and enjoyment remain unassessed.
Kept based on implementing-agent judgment; Jaco's playtest is the next review.
