# House decorations

Independent Pixal3D runtime copies of the four olive-and-pot clusters in the
[asset library](../../../../assets/README.md). Native ImageGen references follow
the [Follow the Light guide](../../../../styles/follow-the-light/README.md).
No stock model pack or external textures were incorporated. Olive-like foliage
and household props are illustrative, not a verified historical reconstruction.

Local +Z faces outward. The mounting code fits width and height, compresses
inferred depth to a shallow pocket and grounds each copy on terrain. These are
static decorations with no interaction or animated foliage.

- Wall A: 149,257 triangles.
- Wall B: 148,878 triangles.
- Basket A: 148,341 triangles.
- Basket B: 215,966 triangles; extra detail retained to avoid damaged pottery.

All use embedded 2K source textures. [Copy hashes](provenance.json).
Twenty instances share the four source geometries/textures. Further performance
optimization is separate from this visual placement review.
