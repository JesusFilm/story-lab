Story Lab shares runnable prototypes, concepts, retrospectives, style guides and
reusable reference images and models. Retain required source credits and licenses.

journals, local machine paths or temporary files. Keep private backups outside this
repository. The portal's explicit build manifest is a runtime inventory, not a
substitute for reviewing files added to the public source repository.
