# GitHub Pages portal

Target: https://jesusfilm.github.io/story-lab/

The portal lives in `projects/portal`. Prototypes retain independent local assets.
The gallery reads explicit model and reference-prompt entries from its publication
manifest. Follow its README to build and verify the complete static output.

Pages is deployed through `.github/workflows/portal-pages.yml`. Keep relative links
working beneath `/story-lab/`. Include model buffers, textures and licenses with each
new entry. Retrospectives remain part of the public demo experience.

The former `story-lab-demos` repository should remain intact until this replacement
is deployed and verified. Do not delete it automatically.
