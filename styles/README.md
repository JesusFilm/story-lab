# Styles

Shared visual guides for generating and adapting assets. Each style has one current
Markdown guide and a small set of reference images.

- [Follow the Light](follow-the-light/README.md): grounded biblical characters and
  environments, tactile materials, warm lamps and blue night.

Link assets to these guides using relative paths. Do not copy style versions,
approval exchanges, provider jobs or temporary paths into asset folders.
